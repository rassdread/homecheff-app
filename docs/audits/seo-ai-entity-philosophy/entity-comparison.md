# Entity comparison — before vs after

## Core entity line

| Surface | Before (Phase 2) | After (Phase 2.1) |
|---------|------------------|-------------------|
| Platform entity (EN) | Digital neighbourhood marketplace for personal craft / local opportunity (food one category) | Explicit **community / people / craftsmanship / creator / neighbourhood-first** + cook·grow·make·repair·design·teach·help·trade·serve·share |
| Platform entity (NL) | Digitale buurtmarkt… | Same reinforcement + mantras wired into `websiteDescription` |
| Homepage SSR H1 definition | Neighbourhood marketplace short line | **Everything starts close to home** + creator-first, not anonymous resale |
| Manifest IS | Digital village square | **Digital neighbourhood marketplace AND digital village square** + five -first stances + distance mantra |
| Manifest IS NOT | Delivery / ads / dropship / anonymous / attention / social / engagement | Added **generic classifieds**, **mass retail**, **ordinary second-hand resale** |
| Meta / OG default | Neighbourhood marketplace craft line | Anti-classifieds / anti-resale / anti-delivery-chain explicit |

## Second-hand

| Before | After |
|--------|-------|
| Often “no resale / not primary” | Permanent rule: **not ordinary second-hand**; **allowed only if craft-transformed** |
| Blocklist: no resale of existing goods | Blocklist: make/grow/transform (upcycle, restore, redesign) |

## Local-first

| Before | After |
|--------|-------|
| Nearby first | Nearby first **+** unique craft may reach further |
| — | Explicit scale path; **never** “international marketplace” branding |
